This project is a premium e-commerce starter built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and a polished storefront/admin structure.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the storefront.

## Included areas

- Storefront home, product listing, product detail, cart, checkout, about, and contact pages
- Admin dashboard and initial admin sections for products, orders, and settings
- Environment template in .env.example

## Next steps

Connect Supabase and Razorpay credentials in .env.local to enable full backend data flow.
