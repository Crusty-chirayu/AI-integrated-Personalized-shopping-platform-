# 🧪 E-Commerce Prototype

> A practice full-stack e-commerce application built to explore modern web technologies, architecture, authentication, database design, and deployment workflows.

---

## Overview

This repository is one of several prototype projects developed while planning and designing **CartIQ**, my final-year AI-powered multi-vendor e-commerce platform.

The purpose of this project was to experiment with different technologies, understand real-world e-commerce architecture, and gain hands-on experience before starting the production version of the project.

Throughout the development process, multiple prototype repositories were created, each focusing on different aspects such as authentication, database design, frontend architecture, API integration, deployment, and AI experimentation. This repository represents one of those development milestones.

Rather than building the final product immediately, these prototypes helped validate ideas, identify design improvements, and understand the complete development workflow.

---

## Objectives

- Learn modern full-stack development
- Understand e-commerce architecture
- Practice authentication and authorization
- Explore database modeling with Prisma
- Experiment with deployment workflows
- Test third-party integrations
- Build a foundation for the final CartIQ project
